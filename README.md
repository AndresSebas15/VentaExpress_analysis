# Cleaning and analysis in Excel VentaExpress

**Objective**

Data cleaning for analysis using basic formulas—such as PROPER, SUBSTITUTE, and TRIM—and PivotTables.

**Databases used**
VentaExpress.xlsx: The data covers technology products (laptops, phones, headphones, tablets) sold via an online platform across various cities in Mexico and Colombia. The dataset includes all sales from October through December 2024 (i.e., the fourth quarter of 2024).

* *Stages completed**

*   Data standardization issues were identified in the "City," "Product," and "Customer" categories; substitution methods were applied based on the criteria outlined in the change log.
*   Null values ​​were found in the "Unit Price" and "Total Amount" fields; these were imputed using the formula specified in the change log.
*   The "Unit Price" and "Total Amount" fields were not formatted as currency.
*   Product category, type, and specifications were originally combined in a single field; these were separated to enable analysis based on product category.
*   Customer names included prefixes that added no analytical value (e.g., "Ing.", "Doc.", "Lic."); these were removed.
